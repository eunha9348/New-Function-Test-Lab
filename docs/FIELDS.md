`src/schema/templates-v2.ts` 에서 직접 생성했으며, Python 스키마(`colab/arc_colab.py`)와 일치함을 확인했습니다.

## 입력 형태 11종

| 형태 | 설명 |
|---|---|
| 텍스트 `text` | 한 줄 입력 |
| 서술형 `longtext` | 여러 줄(긴 글) 입력 |
| 날짜 `date` | 날짜 1개 선택 |
| 기간 `daterange` | 시작일~종료일 (진행 중 표시 가능) |
| 선택 `select` | 드롭다운에서 1개 선택 |
| 체크리스트 `checklist` | 보기 중 복수 선택 |
| 태그 `tags` | 자유 입력 복수 태그 |
| 링크 `link` | URL |
| 파일 `file` | 파일 업로드 |
| 반복 입력 `repeater` | 같은 형식의 항목을 여러 개 추가 (하위 칸으로 구성) |

## 모든 유형 공통 항목

> 실제 폼(`ExperienceFormV2`)에 '기본 정보'라는 섹션은 없습니다. 데이터 모델에서만 공통이고,
> 화면에서는 **경험명·한 줄 요약**이 상단 입력란으로, **증빙 자료**가 마지막 전용 섹션 끝으로,
> **기간·내 역할·핵심 성과**가 접힌 '확장 입력'으로 흩어집니다.
> 전용 항목과 의미가 겹치면 **중복 제거되어 화면에서 숨겨집니다.** 값 자체는 저장됩니다.

## 참고

- 각 항목의 `키`로 폼 상태에 바인딩합니다 — `values[key]`.
- 반복 입력(`repeater`)은 `values[key]`가 배열이고, 각 원소가 `↳` 로 표시된 하위 칸을 가집니다.
  예: `values.tasks[0].metrics`
- `기간(daterange)`은 `{ start, end, ongoing }` 객체입니다.
- '숨겨지는 공통 항목'은 전용 항목이 같은 의미를 덮는 경우입니다. 폼을 그릴 때 둘 다 보여주면
  사용자에게 같은 것을 두 번 묻게 됩니다. `resolveLayout(type)` 이 이미 걸러서 돌려줍니다.

재생성: `npx tsx tools/gen_fields_md.ts`
